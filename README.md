# Proyecto Biblioteca API — Validación UP1

Proyecto didáctico de partida. Contiene una API Express funcional y páginas Markdown que requieren maquetación. Las ramas `feature/docs` y `feature/openapi` aportan archivos adicionales.

La API está en `api/`. No es necesario modificar `server.js`.

El enunciado de la prueba se distribuye por separado.
